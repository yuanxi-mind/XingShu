- 全部模型与训练验收使用固定模拟响应、合成小代码、模拟实验结果和模拟 Docker 调用；真实收费请求与真实服务器训练均为零。

- 上游完整测试集合未作为上述 172 项的一部分，不宣称全仓库全部测试通过。
- 目录包未签名，未生成 NSIS 或会临时解包的自解压 Portable；本源码仓库不包含程序二进制。
